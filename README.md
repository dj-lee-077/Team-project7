# Team Project 7

# 김남주 교수님의 애착템을 소개합니다.

# 팀명 : 남사모(김남주 교수님을 사랑하는 모임)

## 프로젝트 개요

김남주 교수님의 애착템을 하나의 연결고리로 활용하여, 7조 팀원들의 개성과 특징을 소개하는 랜딩페이지를 제작하는 프로젝트임

단순히 팀원의 이름과 정보를 나열하는 자기소개 페이지가 아니라, 하나의 주제와 스토리를 통해 각 팀원을 자연스럽게 소개하는 것을 목표로 하고 있음

또한 프로젝트 진행 과정에서 `README.md`를 지속적으로 수정하고, 이를 바탕으로 랜딩페이지를 기획하고 구현

---

## 기획 의도

페이지의 연출 방식은 애니메이션 「포켓몬스터」의 '누구일까요?' 실루엣 연출을 비튼 메타몽 밈​에서 영감을 받았음

이 밈은 특정 포켓몬의 실루엣을 보여주어 정답을 예상하게 만든 뒤, 실제로는 예상과 전혀 다른 포켓몬이 독특하거나 엉뚱한 자세로 실루엣을 채우고 있었다는 반전을 주는 형식으로 반전의 재미를 요할 수 있을 것이라 기대

우리 팀은 조금 더 재미있고 기억에 남는 방식으로 팀원들을 소개하기 위해 **'김남주 교수님의 애착템'**이라는 공통 소재를 활용하고자 함

애착템을 중심으로 하나의 이야기 흐름을 만들고, 그 과정에서 7조 팀원들의 성격과 특징이 자연스럽게 드러나는 페이지를 기획.

---

## 주요 목표

* 김남주 교수님의 애착템을 활용하여 흥미로운 랜딩페이지를 제작한다.
* 하나의 스토리 안에서 7조 팀원들의 개성과 특징을 자연스럽게 소개한다.
* `README.md`를 프로젝트 기획 문서로 활용하고 지속적으로 수정한다.
* `README.md`의 기획 내용을 바탕으로 실제 랜딩페이지를 구현한다.
* GitHub Commit을 활용하여 프로젝트가 발전하는 과정을 기록한다.
